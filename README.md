# Маркетолог iiko

Telegram-бот, который пишет посты, статьи и формулировки для интерфейса в
стиле iiko и рисует картинки. Внутри Claude Code по подписке, скиллы и база
знаний лежат здесь же.

- Что и зачем: [specs/001-marketeer-bot/spec.md](specs/001-marketeer-bot/spec.md)
- Как устроено: [specs/001-marketeer-bot/plan.md](specs/001-marketeer-bot/plan.md)
- Установка на VPS: [deploy/README.md](deploy/README.md)

Локально: `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt pytest && .venv/bin/pytest`.
