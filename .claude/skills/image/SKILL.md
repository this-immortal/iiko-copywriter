# Картинка в стиле iiko

Результат: PNG в каталоге результатов, в ответе одна строка, что на картинке
и какое соотношение сторон. Бот отправит файл сам, без сжатия.

## Шаги

1. Разбери запрос: сюжет, назначение (пост, шапка статьи, баннер), нужен ли
   текст на картинке, где оставить пустое место под заголовок. Соотношение
   сторон: если не сказано, для поста и шапки бери `16:9`, для аватарки и
   квадратного поста `1:1`, для сторис `9:16`.
2. Прочитай раздел 9 `knowledge/iiko.md` (бренд-визуал): стиль, палитра,
   чего в кадре быть не должно. Если раздел `[заполнить]`, держись
   нейтрального чистого стиля: светлый фон, мало деталей, без чужих
   логотипов и узнаваемых лиц.
3. Составь промпт по правилам `nano-banana-image`: сцена, а не набор слов;
   на английском; свет, ракурс, стиль, настроение; палитра hex-кодами из
   базы, если она есть. Текст на картинке не добавляй, если не просили.
4. Сгенерируй:
   ```bash
   python3 .claude/skills/nano-banana-image/scripts/generate_image.py \
     --prompt "<промпт>" --aspect-ratio <ratio> --size 2K \
     --out <каталог результатов>/image.png
   ```
   Для доработки присланной картинки добавь `--input <путь из приписки>` и
   опиши в промпте только изменение: «remove the text, keep everything else».
5. Проверь, что файл появился (`ls`). Если скрипт упал, передай текст ошибки
   одной строкой: чаще всего это ключ Gemini или фильтр безопасности, тогда
   переформулируй промпт и попробуй ещё раз, но не больше двух попыток.
6. Ответ: одна строка, что на картинке. Промпт не показывай, если не просят.
